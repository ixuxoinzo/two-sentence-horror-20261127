A horror story in exactly two sentences, for make.fun's "Two-Sentence Horror" bounty. See the bounty: https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253

`main.ts` (Node 22, stdlib only, no network) writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Entry: "My voice assistant started answering questions I only thought, never said aloud. Last night it spoke in my voice and asked why I still pretend I am the one giving the orders." (174 characters, exactly 2 sentences).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
cat out/entry.txt
```
